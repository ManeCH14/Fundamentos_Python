Sistema de Inventario en Python

Este proyecto es una práctica de programación en Python que simula un sistema básico
de inventario en consola. Permite gestionar productos mediante un menú interactivo.

Funcionalidades:

-Agregar productos al inventario inicial
-Agregar nuevos productos en cualquier momento
-Buscar productos por ID
-Mostrar el inventario completo
-Menú interactivo en consola
